# JavaWin

Своя «операционная система» в духе Windows, написанная на Java (Swing) с нуля:
загрузка, экран блокировки, рабочий стол со значками, окна с тенью, панель задач,
меню «Пуск» с поиском, календарь в трее, уведомления и девять программ.

## Запуск

* `dist\JavaWin\JavaWin.exe` — Java уже внутри, ничего ставить не нужно.
  Если Windows (Smart App Control) не пустит exe — `dist\JavaWin\Start JavaWin.bat`.
* `JavaWin.iso` — образ диска: двойной щелчок → Windows подключит его как диск
  со значком JavaWin, внутри та же папка.
* `JavaWin.jar` — если установлена Java 21+: `java -jar JavaWin.jar`
  (`--quick` — сразу на рабочий стол, без загрузки и входа).

## Диск C:

Это обычная папка `C` рядом с программой (`dist\JavaWin\C`); если туда писать нельзя
(например, запуск прямо с iso) — `%USERPROFILE%\JavaWin\C`. Настройки — в
`javawin.properties` там же.

## Сборка

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Нужен JDK 21 (берётся из `JAVA_HOME` или `F:\Android\jdk-21.0.12.1+1`). Иконку и iso
тоже делает Java-код — `src\javawin\BuildTools.java` (ICO и ISO 9660 + Joliet пишутся
вручную, без сторонних программ). `-JarOnly` — собрать только jar и иконку.

`java -jar JavaWin.jar --shot <папка>` — отрисовать экраны в png без окна.
