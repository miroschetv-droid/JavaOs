# Чужие программы в JavaOS

JavaOS собирается из бесплатных программ с открытым кодом. Они не входят в этот репозиторий —
скрипт сборки берёт их с официальных сайтов. У каждой своя лицензия:

| Что | Откуда | Лицензия |
|---|---|---|
| Tiny Core Linux 17 (ядро Linux, пакеты) | tinycorelinux.net | GPL и другие (у каждого пакета своя) |
| Java (Eclipse Temurin JRE 21) | adoptium.net | GPLv2 + Classpath Exception |
| Syslinux (загрузчик) | kernel.org | GPL |
| Прошивки NVIDIA GSP, Qualcomm (Wi-Fi/Bluetooth) | linux-firmware (kernel.org) | разрешено распространять, см. linux-firmware |
| Arch Linux (магазин приложений) | archlinux.org — скачивается уже на компьютере | у каждого пакета своя |
| JWM, xdotool, wmctrl, PulseAudio, BlueZ, ntfs-3g | через Tiny Core | GPL / MIT |
