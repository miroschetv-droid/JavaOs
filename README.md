# JavaOS

Операционная система, которая загружается с флешки: Linux + рабочий стол **JavaWin**, похожий на Windows, написанный на Java.

## Что умеет

- Рабочий стол с панелью задач, меню «Пуск», окнами и обоями — на два монитора
- Проводник, Блокнот, Paint, Калькулятор, Терминал (с приколами: `matrix`, `cowsay`, `sl`…)
- Игры: Змейка, 2048, Сапёр
- Часы (секундомер, таймер, будильник), Диктофон, Медиаплеер, Радио и ТВ
- Wi-Fi, Bluetooth (наушники тоже), звук, флешки открываются в Проводнике
- Магазин приложений — программы из Arch Linux (Firefox, Discord, игры…)
- Запуск `.jar`-программ двойным щелчком
- Своя «папка системы» на любом диске — там хранятся файлы, настройки и скачанное

## Как запустить

1. Скачай `JavaOS.iso` в разделе **Releases**.
2. Запиши его на флешку (например, программой Rufus, режим «ISO»).
3. Вставь флешку, включи компьютер и в меню загрузки (F11 / F12 / F8 / Esc) выбери флешку.
4. Появится пингвин с кофе — через 3 секунды загрузится JavaOS.

Если экран чёрный — на экране загрузки напечатай `safe` и нажми Enter.

## Как собрать самому (Windows)

- `JavaWin/build.ps1` — собирает рабочий стол JavaWin (нужен JDK 21)
- `JavaOS/build.ps1` — собирает `JavaOS.iso` (нужен скачанный Tiny Core Linux и JRE в папке `JavaOS/dl`)
- `JavaOS/flash.ps1` — обновляет систему на флешке

## Что внутри

- `JavaWin/src` — рабочий стол и все приложения (Java Swing)
- `JavaOS/os` — скрипты системы: загрузка, графика, Wi-Fi, Bluetooth, звук, Arch Linux, папка системы
- `JavaOS/tools` — инструменты для проверки в виртуальной машине

Чужие программы, которые использует система, перечислены в [NOTICE.md](NOTICE.md).
